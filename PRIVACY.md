# PaperSetGPT privacy

PaperSetGPT does not collect, transmit, sell, or share user data.

The browser extension runs only on ChatGPT origins. To provide its reading and rendering controls, it processes the structure and content of the ChatGPT page locally in the browser so it can identify conversation turns, text, and images and apply the selected display behavior. Conversation text, prompts, responses, account information, and browsing activity are not stored by PaperSetGPT or transmitted to the developer or any third party.

PaperSetGPT stores only its own display and rendering preferences in Chrome/Brave extension storage. It has no analytics, telemetry, background service worker, remote API, CDN, or extension-originated network requests.

The separate macOS setup helper changes only allowlisted Brave preferences and does not read or copy ChatGPT conversations, cookies, history, passwords, authentication data, or other personal browser state.

PaperSetGPT's use of information available through Chrome extension APIs is limited to providing its disclosed user-facing reading and rendering features and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

ChatGPT, Chrome, and Brave remain separate services with their own privacy practices. PaperSetGPT is an independent, unofficial project and is not affiliated with OpenAI, Google, or Brave Software.
