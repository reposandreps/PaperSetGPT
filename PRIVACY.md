# PaperSetGPT privacy

PaperSetGPT does not collect, transmit, sell, or share user data.

The browser extension runs only on ChatGPT origins and stores its own display and rendering preferences locally through Chrome/Brave extension storage. It has no analytics, telemetry, background service worker, remote API, CDN, or extension-originated network requests.

The setup helper changes only allowlisted Brave preferences and does not read or copy ChatGPT conversations, cookies, history, passwords, authentication data, or other personal browser state.

ChatGPT and Brave remain separate services with their own privacy practices. PaperSetGPT is an independent, unofficial project and is not affiliated with OpenAI or Brave Software.
